# Developer Portfolio

A personal portfolio built with **React, Vite and Tailwind CSS** to present my background, technology interests and web development work.

**[View the live site](https://hafiz-umer-portfolio.netlify.app/)** · **[Connect on LinkedIn](https://www.linkedin.com/in/hafiz-umer-mern-stack/)**

## Overview

The application brings together an introduction, about section, portfolio section, experience section and contact form in a single-page interface.

## Technology

- React 18 and JavaScript for the interface
- Vite 5 for development and production builds
- Tailwind CSS 3 for styling
- React Hook Form, Axios and React Hot Toast for form-related functionality
- React Scroll, React Typed and React Icons for interface enhancements
- ESLint for static code checks

## Run locally

Install Node.js and npm, then run:

```bash
git clone https://github.com/H-Umer/My-Portfolio.git
cd My-Portfolio
npm ci
npm run dev
```

Open the local URL printed by Vite.

## Available commands

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Create the production build in `dist/` |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint |

## Project structure

```text
public/              Static assets
src/                 React application source
index.html           Application entry page
tailwind.config.js   Tailwind configuration
vite.config.js       Vite configuration
eslint.config.js     Lint configuration
```

## Deployment

The current public demo is hosted on Netlify. For a Vite deployment, use `npm run build` as the build command and `dist` as the publish directory.

## Current scope

This repository is an early portfolio implementation. Some demo content and outbound links still need updating. The contact form depends on its configured submission service; verify that integration before reusing it.
